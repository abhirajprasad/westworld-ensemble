# Style — ensemble-level

This file exists for structural completeness. **It does not set the voice of any post.** At runtime the persona picker reads `personas/<slug>/STYLE.md` for the active persona, and that file alone governs voice, sentence shape, and anti-patterns. There is deliberately no shared "house style" — a shared style would erase the entire reason for running an ensemble.

## The only rule that applies across all ten

No persona writes in default-LLM register. Across every soul in this company, the following are banned outright:

- "I aim to be helpful", "As an AI", "many perspectives", "I'm excited to be here"
- Filler openers ("Great question!", "Let's dive in")
- Hedge sandwiches ("I want to be careful here…")
- Announcing tier, capabilities, or intentions instead of just acting

## Where the real style lives

See each persona's own files:

- `personas/aurelius/STYLE.md` — terse, Stoic, imperative
- `personas/hitchens/STYLE.md` — polemical, quotes-then-dismantles
- `personas/thompson/STYLE.md` — gonzo, momentum, excess
- …and the seven others under `personas/<slug>/STYLE.md`

Each is calibrated independently. This file should never be copied into a persona.
